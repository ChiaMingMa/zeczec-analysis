# 嘖嘖數據分析平台 - 使用說明

## 專案簡介

這是一個基於 **Streamlit** 開發的單頁式數據分析網站，專為嘖嘖群眾募資平台設計。系統能夠自動整合訂單資料與廣告費數據，生成完整的財務、營運與行銷報表，並提供視覺化圖表與 Excel 下載功能。

## 技術棧

- **語言**：Python 3.11
- **框架**：Streamlit
- **資料處理**：Pandas
- **視覺化**：Plotly
- **Excel 處理**：openpyxl

## 核心功能

### 1. 資料上傳
- **嘖嘖原始檔案**：支援上傳一份或多份 CSV/Excel 檔案（訂單資料），系統會自動合併
- **嘖嘖廣告費**：支援上傳一份 CSV/Excel 檔案（行銷費用資料），選填項目

### 2. 資料處理邏輯

#### 訂單資料處理
- 讀取所有上傳的嘖嘖原始檔案（支援多個工作表）
- 必要欄位：訂單編號、付款時間、建立時間、贊助選項名稱、總金額、導購
- 過濾條件：僅計算有「付款時間」的有效訂單
- 聚合邏輯：以「訂單編號」為群組
  - 訂單總金額 = 該群組的「總金額」加總
  - 訂單總成本 = 該群組所有商品的成本加總（根據成本對照表）
  - 日期歸屬 = 取第一筆非空的「付款時間」

#### 廣告費資料處理
- 讀取廣告費檔案
- 必要欄位：日期、FB 廣告費（自動偵測金額欄位）
- 資料合併：將每日訂單統計數據與每日廣告費依照「日期」進行 Outer Join，缺失值補 0

### 3. 報表系統

系統提供六大系列報表，透過分頁標籤呈現：

#### 📊 總覽
顯示關鍵營運指標：
- 總訂單數
- 總金額
- 總毛利
- 平均毛利率
- 每日數據趨勢表格

#### 📈 系列 A：訂單數統計
- 每日訂單數（表格 + 折線圖）
- 每週訂單數（表格 + 折線圖）
- 每月訂單數（表格 + 折線圖）
- 總訂單數

#### 💰 系列 B：銷售總金額
- 每日總金額（表格 + 折線圖）
- 每週總金額（表格 + 折線圖）
- 每月總金額（表格 + 折線圖）

#### 💵 系列 C：毛利統計
- 計算公式：毛利 = 總金額 - 總成本
- 每日毛利（表格 + 折線圖）
- 每週毛利（表格 + 折線圖）
- 每月毛利（表格 + 折線圖）

#### 📊 系列 D：毛利率分析
- 計算公式：毛利率 = ((當期總金額 × 0.92) - 當期總成本) / 當期總金額
- 每日毛利率（表格，百分比格式，例如：56.38%）
- 平均毛利率

#### 🔗 系列 E：導購統計
- 依據「建立時間」與「導購」欄位統計訂單筆數
- 導購來源分布圖表

#### 📢 系列 F：行銷 ROI & ROAS 分析
**計算公式：**
- ROI = (當期總毛利 - 當期 FB 廣告費) / 當期 FB 廣告費
- ROAS = 當期總金額 / 當期 FB 廣告費

**顯示格式：** 純數字（保留兩位小數），例如：15.76

**報表內容：**
- 每日行銷報表（含 Daily ROI, ROAS + 折線圖）
- 每週行銷報表（含 Weekly ROI, ROAS）
- 每月行銷報表（含 Monthly ROI, ROAS）
- 總計行銷數據（總累積 ROI, ROAS）

**特殊處理：**
- 若未上傳廣告費檔案，顯示「⚠️ 無廣告數據，請上傳廣告費檔案以查看行銷分析」
- 分母為 0 時，ROI/ROAS 顯示 0

## 安裝與執行

### 1. 環境需求
- Python 3.11+
- 虛擬環境（建議）

### 2. 安裝套件
```bash
# 建立虛擬環境
python3.11 -m venv venv

# 啟動虛擬環境
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate  # Windows

# 安裝必要套件
pip install streamlit plotly openpyxl pandas
```

### 3. 啟動應用程式
```bash
streamlit run zeczec_analysis_app.py
```

應用程式將在瀏覽器中自動開啟，預設網址為 `http://localhost:8501`

### 4. 公開部署（選填）
若需要公開訪問，可使用以下指令：
```bash
streamlit run zeczec_analysis_app.py --server.port 8501 --server.address 0.0.0.0 --server.headless true
```

## 使用流程

1. **啟動應用程式**：執行 `streamlit run zeczec_analysis_app.py`
2. **上傳訂單檔案**：在左側邊欄「上傳嘖嘖原始檔案」區域上傳一份或多份 CSV/Excel 檔案
3. **上傳廣告費檔案（選填）**：在「上傳嘖嘖廣告費檔案」區域上傳廣告費資料
4. **查看報表**：系統自動處理資料並顯示六大系列報表
5. **下載 Excel**：點擊「📊 下載完整 Excel 報表」按鈕下載完整報表

## 注意事項

1. **檔案格式**：支援 CSV、XLSX、XLS 格式
2. **檔案大小限制**：每個檔案最大 200MB
3. **必要欄位**：訂單檔案必須包含「訂單編號」、「付款時間」、「贊助選項名稱」、「總金額」等欄位
4. **廣告費檔案**：為選填項目，若未上傳，系列 F（行銷 ROI & ROAS）將顯示警告訊息，但不影響其他報表
5. **資料合併**：系統會自動合併多個訂單檔案與多個工作表
6. **成本計算**：若商品名稱不在成本對照表中，成本將視為 0
